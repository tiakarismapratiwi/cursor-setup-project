# cursor-setup-project - Cursor & GitHub Setup

## About This Project

This repository was created as part of the 100Hires assessment process.

The objective of this task was to install several tools, create a GitHub repository, document the setup process, and demonstrate the ability to learn new technologies independently.

As a final-year student at IPB University with experience in fundraising, partnership development, stakeholder management, and project coordination, this project helped me become more familiar with AI-assisted development tools and GitHub workflows.

## Tools Installed

- Cursor IDE
- Claude Code Extension
- Codex Extension
- Git
- GitHub

## Steps Completed

1. Installed Cursor IDE
2. Created a public GitHub repository
3. Installed Claude Code extension
4. Installed Codex extension
5. Opened the repository in Cursor
6. Created this README documentation
7. Committed and pushed the repository to GitHub

## Challenges Encountered

### Challenge 1: Understanding Cursor Interface

As a first-time Cursor user, I initially had difficulty understanding the difference between the Home View and the Editor Window. Because of this, I could not find some features such as Git commands and extensions.

### Solution

I explored the interface, searched for tutorials, and learned how Cursor organizes its workspace. After opening the Editor Window, I was able to access the development features properly.

### Challenge 2: Learning Git and GitHub Workflow

I had limited practical experience with Git repositories, especially cloning repositories, committing changes, and pushing updates.

### Solution

I researched the workflow, installed Git, and practiced using repositories directly while completing this project.

### Challenge 3: Installing AI Development Tools

I needed to install and understand new AI-powered tools such as Cursor, Claude Code, and Codex.

### Solution

I followed the documentation, explored the features, and learned how these tools can support productivity and problem solving.

## Key Learnings

- Independent learning is essential when working with new tools.
- Documentation helps organize knowledge and progress.
- GitHub is an important platform for collaboration and project management.
- AI tools can improve productivity when used effectively.
